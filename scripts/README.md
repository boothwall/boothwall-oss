# scripts

The repo's tooling, all plain Node (`.mjs`, no build step).

| Folder         | Run as                           | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `boothwall/`   | `pnpm boothwall <command>`       | The CLI: `setup` creates the Cloudflare resources and deploys, `deploy` redeploys, `migrate` applies D1 migrations, `demo` runs API and web locally with demo photos (`pnpm demo`, `--lan` for your network, `--tv` for `pnpm try`), `example` applies one of `examples/`, and `settings-preview` / `settings-apply` move older saved settings into the config ([guide](../docs/config-migration.md)). `commands/` holds one file per command, `lib/` what they share (the cf wrapper, the config file, paths, output). |
| `brand/`       | `node scripts/brand/render.mjs`  | Renders the logos, icons and marks the apps ship from the SVG sources in `brand/`.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `themes/`      | `node scripts/themes/render.mjs` | Draws each wall theme's backdrop and moving layers in code and writes the images `@boothwall/wall-ui` bundles.                                                                                                                                                                                                                                                                                                                                                                                                          |
| `remote/`      | `pnpm remote`                    | A remote control in your browser that sends real key presses to the Virtual Device or a Stick.                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `postinstall/` | runs on `pnpm install`           | Links `@cloudflare/vite-plugin` into each app's `node_modules`, where the `cf` CLI expects it in a hoisted install.                                                                                                                                                                                                                                                                                                                                                                                                     |

The CLI's `lib/paths.mjs` is the one place that knows where the config file, the demo photos and the apps live; update it when those move.
