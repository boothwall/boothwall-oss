# Security

BoothWall puts a public upload page in front of a screen at a live event, so security reports are very welcome.

Please report anything you find privately through GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately): open the repo's **Security** tab and choose **Report a vulnerability**. Only you and the maintainer see the report. Don't open a public issue for it.

Useful to include: what you found, how to reproduce it, and which version you were running. I'll reply as soon as I can and credit you in the fix unless you'd rather stay anonymous.

Fixes go into `main`. Older versions, including the `devcon-2026` branch, aren't maintained.
